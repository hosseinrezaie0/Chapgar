**Chapgar** (چاپگر - Persian for *Printer*) enables AI agents (such as Claude Desktop, Antigravity IDE, Cursor, or Windsurf) to generate beautiful, pixel-perfect Persian PDFs with native Right-to-Left formatting, zero bidirectional layout glitches, embedded typography, and automatic digit localization.

---

## 🎭 Before / after

You ask your AI agent for a Persian PDF report. Without Chapgar, your agent attempts to write raw LaTeX, struggles with `xepersian` dependencies, fails to load local fonts, breaks alignment when mixing English words, and hallucinates complex build commands.

With Chapgar via MCP:

```typst
= گزارش فروش
این یک گزارش ساده است که شامل اعداد 123 و کلمات انگلیسی مانند Report می‌باشد.
```

*That's it. The agent just writes plain content. Chapgar automatically handles the Right-to-Left layout, embeds the Vazirmatn font, converts `123` to `۱۲۳`, and compiles the PDF instantly.*

---

## ⚙️ How it works

When an AI agent calls the `generate_persian_pdf` MCP tool, it doesn't need to know anything about Persian typography. Chapgar takes the raw input and applies a robust pipeline before compilation:

```text
1. Font Injection      → Automatically loads 'Vazirmatn' and 'Estedad'.
2. Directionality      → Enforces global Right-to-Left document flow.
3. Digit Localization  → Converts standard numerals (0-9) to Persian digits (۰-۹).
4. BiDi Handling       → Leverages Typst to seamlessly mix Persian, English, and code.
5. Clean Execution     → Compiles locally and returns the PDF path.
```

---

## 📊 The Impact

Large Language Models are notoriously bad at generating correct LaTeX for RTL languages. They often waste time (and context window tokens) outputting huge preambles, debugging font errors, and explaining why the PDF compilation failed.

By delegating the layout and compilation to Chapgar:
- **~90% less boilerplate** generated by the agent.
- **100% correct** RTL and BiDi rendering.
- **Zero** LaTeX dependencies or environment setup.
- **Cheaper and faster** agent responses.

---

## ✨ Features

- 🟢 **MCP Native**: Plugs directly into any Model Context Protocol host as a dedicated tool (`generate_persian_pdf`).
- ⚡ **Powered by Typst**: Blazing fast compilation without heavy TeX/LaTeX dependencies.
- 🔤 **Embedded High-Quality Fonts**: Pre-packaged with open-source **Vazirmatn** and **Estedad** fonts out of the box.
- ↔️ **Flawless RTL & BiDi Handling**: Native handling of mixed Persian and English text, inline code, mirrored brackets/parentheses, bullet points, and RTL tables.
- 🔢 **Automatic Digit Localization**: Built-in rules to automatically map Western numerals (`0-9`) to Persian numerals (`۰-۹`).
- 🧹 **Clean Execution**: Isolated compilation engine with automated temporary file cleanup.

## 📦 Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/hosseinrezaie0/Chapgar.git
   cd Chapgar
   ```

2. **Create a virtual environment & install dependencies**:
   ```bash
   python -m venv .venv
   
   # Windows (PowerShell / CMD)
   .venv\Scripts\activate
   
   # Linux / macOS
   source .venv/bin/activate
   
   pip install -r requirements.txt
   ```

## ⚙️ MCP Integration Guide

Add **Chapgar** to your preferred AI app or agent framework using the configuration guides below (replace `C:\path\to\Chapgar` or `/path/to/Chapgar` with your actual project location):

---

### 1. 🟧 Claude Desktop

To install custom MCP servers in Claude Desktop, you need to update `claude_desktop_config.json` file.

#### Configuration File Location:
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`  
- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Linux**: `~/.config/Claude/claude_desktop_config.json`

#### Add to `claude_desktop_config.json`:

**Windows Example:**
```json
{
  "mcpServers": {
    "chapgar": {
      "command": "C:\\path\\to\\Chapgar\\.venv\\Scripts\\python.exe",
      "args": [
        "C:\\path\\to\\Chapgar\\server.py"
      ]
    }
  }
}
```

**macOS / Linux Example:**
```json
{
  "mcpServers": {
    "chapgar": {
      "command": "/path/to/Chapgar/.venv/bin/python",
      "args": [
        "/path/to/Chapgar/server.py"
      ]
    }
  }
}
```

After updating the file, **restart Claude Desktop**. You should see a "plug" icon (or hammer icon) in your chat indicating the `generate_persian_pdf` tool is now available.

---

### 2. ⚡ OpenCode CLI (`opencode`)

OpenCode CLI reads MCP servers from `opencode.json` (located in your project root or `~/.config/opencode/opencode.json`).

#### `opencode.json`:
```json
{
  "mcp": {
    "chapgar": {
      "type": "local",
      "command": [
        "C:\\path\\to\\Chapgar\\.venv\\Scripts\\python.exe",
        "C:\\path\\to\\Chapgar\\server.py"
      ]
    }
  }
}
```

Or run via CLI:
```bash
opencode mcp add chapgar -- "C:\path\to\Chapgar\.venv\Scripts\python.exe" "C:\path\to\Chapgar\server.py"
```

---

### 3. 🌐 AnythingLLM Desktop

AnythingLLM supports stdio MCP tools directly in the desktop interface or via config files.

#### Option A: Via GUI (Recommended)
1. Open **AnythingLLM Desktop**.
2. Go to **Settings** (⚙️) -> **Agent Skills** / **MCP Servers**.
3. Click **Add Custom MCP Server**.
4. Enter the details:
   - **Server Name**: `chapgar`
   - **Command**: `C:\path\to\Chapgar\.venv\Scripts\python.exe` *(or `/path/to/Chapgar/.venv/bin/python`)*
   - **Arguments**: `C:\path\to\Chapgar\server.py` *(or `/path/to/Chapgar/server.py`)*
5. Save & restart agent workspace.

#### Option B: Via `mcp.json` Config
Create or edit `%APPDATA%\anythingllm-desktop\mcp.json`:
```json
{
  "mcpServers": {
    "chapgar": {
      "command": "C:\\path\\to\\Chapgar\\.venv\\Scripts\\python.exe",
      "args": [
        "C:\\path\\to\\Chapgar\\server.py"
      ]
    }
  }
}
```

---

### 4. 🚀 Antigravity App / IDE

## 🚀 Usage

Once connected via MCP, your AI assistant can use the `generate_persian_pdf` tool automatically when asked to build PDFs in Persian.

### Example AI Prompts
> "یک گزارش مدیریتی فارسی به همراه جدول فروش و لیست اقدامات آتی به فرمت PDF تولید کن."

> "یک فاکتور رسمی فروش به زبان فارسی با فونت وزیرمتن و شماره‌گذاری فارسی در فایل invoice.pdf ذخیره کن."

### Direct Python API Usage
You can also invoke the core generator programmatically:

```python
from core.generator import create_pdf

typst_markup = """
= گزارش نمونه
این یک متن نمونه فارسی است که با *وزیرمتن* رندر شده است.

- آیتم اول
- آیتm دوم
"""

output_path = create_pdf(typst_markup, "sample.pdf")
print(f"PDF created at: {output_path}")
```
